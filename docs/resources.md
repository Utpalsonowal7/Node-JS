## How to use a reference

1. Search the exact API or behavior you are using.
2. Confirm the page applies to your supported Node release.
3. Copy the smallest example into a scratch file.
4. Change one condition and observe the result.
5. Record a note only if it helps you make a decision or avoid a bug.
